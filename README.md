VELMARA — a travel poster for a place that isn't there: an island cliff at golden hour where the sea falls UP, arcing from the cliff edge into the sky and breaking into light. Deep teal sea, gold sun, one hero landmark, one small sailboat. The only text on the poster is the place name, set in Bodoni Moda Bold from a real-type bitmap atlas.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024) to `/output` (or `$MAKEFUN_OUTPUT_DIR`). Python 3.13, standard library only, no network, deterministic.
